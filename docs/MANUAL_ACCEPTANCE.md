# Manual acceptance

Normal use: double-click the full root ae-strom.exe, with local-data/player beside it. Confirm the existing banks/stations/EQ, real mode and Stopped startup, then intentionally Play. Do not use --fake for normal listening. Moving the EXE requires moving its profile to retain settings.

1. Confirm no white/intermediate startup frame and correct restored/clamped position. Check actual monitor/DPI transitions and 100%/150% Windows scale.
2. Drag noninteractive background/ticker/channel in normal/compact modes. Buttons, volume and Settings retain their own gestures.
3. Select long synthetic URLs in right slots 6–0, horizontal scroll both ways, use keyboard selection/clipboard/IME; highlight stays inside the input.
4. Check uniform Noto Sans, Æ/ø/Cyrillic, 110 px presets with 24×24 arrow area, banks/slots/drafts. EQ retains gray tracks, dark grips, shared grid, bottom labels and transient values.
5. Normal 725×36, compact 102×36, Settings 725×258, EQ 725×257. Empty slots/errors must not add a row. Ctrl+C outside editors copies the full title.
6. Close/restart and confirm persisted station, EQ and volume/mute. Startup must not autoplay. Fake tests use explicit --fake and a separate synthetic profile.

Automated native single-EXE save/restart, 33 native fake checks and two short approved live backend phases passed. Non-silent callbacks do not establish audible quality; the user's ears remain the listening check. Long soak, physical input/accessibility, installers/signing and non-Windows remain unverified.
